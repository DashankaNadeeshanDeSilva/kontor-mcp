## 4. Task 3.1 design (approved by the owner 2026-08-26)

- **Host:** SDK 1.30.0 `createMcpExpressApp({ host })` (Express 5 is an SDK dependency — no new direct dependency) + one `StreamableHTTPServerTransport` per session (`sessionIdGenerator: randomUUID`; session map cleaned on transport close and on `DELETE /mcp`). Same `createServer()` factory as stdio → identical tool surface.
- **Auth:** Bearer token from `KONTOR_AUTH_TOKEN`, compared with `crypto.timingSafeEqual` → 401 on missing/wrong. HTTP mode refuses to start without a token unless `KONTOR_BIND` is loopback *and* `KONTOR_ALLOW_NO_AUTH=1`.
- **Origin:** requests without `Origin` (non-browser clients) pass; with `Origin`, only `http(s)://localhost|127.0.0.1|[::1](:port)` or entries of `KONTOR_ALLOWED_ORIGINS` → otherwise 403. Host-header / DNS-rebinding protection comes from the SDK when bound to loopback (default `127.0.0.1`).
- **Config:** `KONTOR_TRANSPORT=stdio|http` (default stdio), `KONTOR_PORT` (3333), `KONTOR_BIND` (127.0.0.1), `KONTOR_AUTH_TOKEN`, `KONTOR_ALLOWED_ORIGINS`; `bin.ts` dispatches. Graceful shutdown on SIGINT/SIGTERM (close transports, then the HTTP server). JSON body cap aligned with `KONTOR_MAX_FILE_MB`. TLS is the reverse proxy's job (document in SECURITY.md).
- **Tests (TDD, in-process `StreamableHTTPClientTransport` on an ephemeral port):** connects with token and lists tools; 401 without / wrong token; 403 on spoofed Origin; `DELETE` terminates the session; stdio suite unchanged. Docs: server README HTTP section, SECURITY.md, CHANGELOG, D-044.
