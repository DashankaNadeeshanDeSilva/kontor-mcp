## 3. Things that bit us this session (don't repeat)

- **Python heredocs with `—`/umlauts silently die without `LC_ALL=en_US.UTF-8`** — and a following `git commit -A` then commits *partial* work (`3187565`). Always `export LC_ALL=en_US.UTF-8` first and check the script printed its success line.
- **A colon inside an unquoted YAML step name** (`name: Pack check (…: …)`) breaks the entire workflow file → run "failed" with zero jobs. `python3 -c "import yaml; yaml.safe_load(open(f))"` both workflows before pushing.
- undici's `fetch` **drops a caller-set `Host` header** — test host validation with `node:http`.
- zsh does not word-split `$CMD` variables; CI is bash.
- Biome reformats multi-line lists — a Python `str.replace` written against the pre-format text silently does nothing; assert the needle exists.
- The MCP Inspector CLI swallows `-e`/`-i` flags meant for `docker run` — wrap in a script (`tools/docker-stdio-offline.sh`).
- pnpm 10 `deploy` needs `inject-workspace-packages`; use `--legacy`.
- Registry `server.json` description max 100 chars.
