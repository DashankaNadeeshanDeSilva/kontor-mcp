## 4. Gotchas from this session

- Browser login to npmjs.com does **not** log in the CLI — `npm whoami` was 401 until `npm login`.
- `publishConfig.provenance: true` makes a *local* publish fail; pass `--provenance=false` for the one-time manual publish only.
- `npx @kontor-mcp/server --help` "hangs" — there is no `--help` handler; the stdio server just waits on stdin. Smoke-test by piping an `initialize` request instead.
- Org-scoped packages show under the **org's** Packages page, not the user profile.
