## What is Kontor-MCP ?

Kontor MCP is a local, offline toolbox that lets AI assistants (Claude Desktop/Code, etc.) handle German/EU e-invoices (XRechnung, ZUGFeRD/Factur-X per EN 16931). It can read an invoice (bare XML or XML embedded in a PDF), check it against the official KoSIT/EN 16931 rulebooks, explain cryptic errors in German/English, create valid new invoices (XML or ZUGFeRD PDF/A-3), convert between formats, and tell a business which legal obligations apply. The key promise is sovereignty: no cloud, no API keys, no network calls, no Java at runtime — proven by tests.

Technically it's a pnpm TypeScript monorepo with 4 packages: core (pure library), rules (bundled schemas/compiled Schematron/knowledge base), server (MCP server, stdio + Streamable HTTP with bearer auth, 8 tools + resources + prompts), and client (a small CLI agent). The make-or-break risk is executing the official Schematron rules in pure JS (Schematron → XSLT → SEF → Saxon-JS), so the plan is riskiest-first: Phase 0 spikes that before any tools are built. Correctness is proven in CI by diffing against the Java KoSIT validator (oracle) and veraPDF for PDF/A-3. It's also a portfolio piece (HUB.KI / AI Tinkerers Bremen demo).
